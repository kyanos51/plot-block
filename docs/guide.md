# 플롯 블록 사용 가이드

## 설치 (iPhone)
1. Safari로 https://kyanos51.github.io/plot-block/ 에 접속
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 **플롯블록** 아이콘으로 실행 (첫 실행 뒤에는 인터넷 없이도 열림)

## 화면 구성
| 위치 | 내용 |
|---|---|
| 위쪽 바 | 화수 검색, 되돌리기(편집·글 모드에서만), 편집, 글, 터뜨리기, ⋯(설정) |
| 가운데 | 타임라인 시트. 위에서 아래로 화수가 진행 (데스크탑은 왼쪽→오른쪽) |
| 아래쪽 | 트레이 (편집 모드에서만, 데스크탑은 항상) |

## 모드
| 모드 | 켜는 법 | 할 수 있는 것 |
|---|---|---|
| 기본 | (아무것도 안 켬) | 블록 긋기로 터뜨리기, 블록 길게 눌러 세부 메모, 빈 곳에서 스크롤 |
| 편집 | 위쪽 **편집** | 블록 추가·이동·삭제·색 바꾸기, 시트 추가 |
| 글 | 위쪽 **글** | 블록 요약 메모 쓰기, 말풍선 위치 옮기기 |

편집과 글 모드는 다시 누르면(**완료**) 꺼집니다.

## 블록
- **추가**: 편집 모드에서 트레이의 색을 시트 빈칸으로 끌어다 놓기
- **이동**: 편집 모드에서 블록을 끌기. 화면 위·아래 끝에 0.4초 머물면 자동 스크롤
- **삭제**: 편집 모드에서 블록을 트레이 오른쪽 **삭제** 칸에 놓기
- **블록 하나 색 바꾸기**: 트레이의 다른 색을 그 블록 위에 놓기
- **색 슬롯 바꾸기**: 트레이의 **+** → 색 칸을 눌러 새 색 고르기. 그 색의 블록이 모두 바뀜. **초기화**로 프리셋 복귀
- **되돌리기**: 편집·글 모드의 **되돌리기** (최대 20단계, 앱을 닫으면 기록이 사라짐)

## 요약 메모 (블록에 보이는 짧은 글)
1. **글** 모드에서 블록을 탭 → 위쪽 입력 창에 쓰기 (최대 24자)
2. 메모를 끌어 블록의 위·아래·왼쪽·오른쪽 빈칸에 놓으면 말풍선으로 붙음
3. 자기 블록 위에 놓거나 입력 창의 **블록 안으로**를 누르면 다시 블록 안으로

## 세부 메모
- 기본 모드에서 블록을 **길게 누르기** (테두리가 드러나면서 열림)
- 같은 색 블록의 메모가 시트 순서대로 나열되고, 누른 블록의 메모가 맨 위
- 카드마다 제목, 본문, 완성도(설계·검토·완성)
- 위쪽 칸: **색 의미** (같은 색 메모 전체에 적용)
- **전체 복사**: 그 색의 모든 메모를 `[화수] 제목` / 본문 / 태그 형식으로 복사

### 태그 (다른 메모로 이동)
- 본문 아래 태그란에 다른 메모의 **제목**을 쓰면 태그 버튼이 생김
  - 쓰는 중에 맞는 제목이 앞 시트부터 5개 추천됨 (초성만 써도 됨). 누르면 바로 태그
  - 본문에 `#제목`을 써도 입력을 마치면 태그란으로 옮겨짐
- 태그 버튼을 누르면 그 메모로 이동 (다른 색이면 그 색 목록으로). **‹ 뒤로**로 돌아오기
- **×**로 태그 지우기

## 시트
- **화수 라벨**을 탭 → 화수 구간, 시트 메모, 시트 삭제
- **+ 시트 추가**: 편집 모드에서 시트 목록 맨 아래
- **화수 검색**: 위쪽 검색 칸에 숫자 입력 → 0.7초 뒤 그 화수가 들어 있는 시트로 이동

## 터뜨리기
- 기본 모드에서 블록 위에서 시작해 **같은 색 블록**을 그어 잇고 손 떼기 (2~5개)
- 빈칸과 같은 색 블록 위로만 지나갈 수 있음. 다른 색에 닿으면 무효
- 완성 단계 블록이 섞이면 금색 연출, 모두 완성이면 별자리 연출
- **콤보**: 1초 안에 다른 색을 이어서 터뜨리면 콤보가 오르고, 아래에 누적 블록 수 표시
- 위쪽 **터뜨리기**를 눌러 끄면 블록 위에서도 스크롤만 됨

## 백업 (중요)
데이터는 이 기기 안에만 저장됩니다. 기기를 바꾸거나 데이터가 지워지면 백업 파일로만 되살릴 수 있습니다.
- **⋯ → 백업 파일 만들기** → 공유 창에서 **파일에 저장**
- **⋯ → 백업 파일로 복구** → 저장해 둔 파일 고르기 (복구 직후 되돌리기 가능)
- 7일 넘게 백업하지 않으면 위쪽에 알림이 뜸

## 설정 (⋯)
- 블록 외곽선 켜기/끄기
- 바깥 메모 글자 작게(11px)/크게(12px)
- 모든 데이터 지우기 (처음 예시로 되돌아감, 되돌릴 수 없음)
