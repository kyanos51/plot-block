# 플롯 블록 개발 로드맵 v1.0

## 기준
- 작업량: 하루 2시간. 1일 = 1세션
- 역할: 코드는 Claude가 작성하고, 사용자는 iPhone 실기기 테스트·피드백·결정을 맡음
- 원칙: 각 Phase의 완료 기준을 통과해야 다음 Phase로 넘어감
- 예상 총 기간: **약 39세션 (주 5일 기준 약 8주)**
  - 추정치이며, 손맛 튜닝을 몇 번 반복하느냐에 따라 가장 크게 달라짐

---

## Phase 0. 준비 (3세션)

| 세션 | 작업 | 산출물 |
|---|---|---|
| 1 | GitHub 계정과 저장소 생성, Pages 설정 | 테스트 주소 |
| 2 | iPhone에서 접속, 홈 화면 설치 확인 | 설치된 테스트 앱 |
| 3 | **iOS 검증**: 햅틱 우회 방법, 터치 반응 속도, 길게 누르기 시 Safari 기본 메뉴 차단 | 검증 결과 메모 |

**완료 기준:** iPhone에서 앱이 실행되고, 진동 방침(햅틱 또는 시각 대체)이 결정됨

**결과 (완료):** 진동 불가 확인, 시각 피드백으로 대체하기로 결정. 상세 내용은 기획서 11장

## 테스트 체크리스트 (Phase마다 반복)
- [ ] iPhone 실기기에서 끊김 없음 (60fps 체감)
- [ ] 기본 모드에서 블록이 의도치 않게 움직이지 않음
- [ ] 스크롤과 긋기가 섞이지 않음
- [ ] 길게 누를 때 Safari 기본 메뉴(텍스트 선택, 확대)가 뜨지 않음
- [ ] 앱을 다시 실행해도 데이터 유지
- [ ] 백업 파일로 완전 복구
