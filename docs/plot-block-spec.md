# 플롯 블록 기획서 v1.0

> 상태: 확정. 단, `[가정]` 표시 항목은 답변이 없거나 해석이 들어간 부분이며, 프로토타입 테스트에서 검증한다.
> 원칙: 블록 쌓기와 터뜨리기 프로토타입을 먼저 만들어 사용자 테스트를 하고, 그 결과로 제스처와 디자인을 확정한 뒤 나머지 기능을 개발한다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 플롯을 정사각형 블록으로 시각화하는 개인용 라이팅 보조 도구 |
| 사용자 | 본인 1인 |
| 주 사용 기기 | **iPhone (iOS Safari)**, 세로 화면 |
| 보조 환경 | 데스크탑 (가로 화면) |
| 핵심 가치 | ① 블록 배치의 손맛 ② 퍼즐 게임 같은 터뜨리기 연출 |
| 프로젝트 수 | 1개 |
| 동기화 | 없음 (기기 로컬 저장, 보안 우선) |
| 사운드 | 없음 |
| 다크모드 | 미지원. 항상 같은 배경색 사용 |

## 2. 화면 구성

### 2-1. 모바일 (세로, 우선)
- 타임라인 시트: 위에서 아래로 진행
- 블록 트레이: 편집 모드에서만 화면 하단에 작게 표시
- 상단 바: 화수 검색, 블록 편집 모드, 텍스트 편집 모드, 터뜨리기 끄기, 메뉴(백업 등)

### 2-2. 데스크탑 (가로)
- 타임라인 시트: 왼쪽에서 오른쪽으로 진행
- 블록 트레이: 시트 가운데 아래에 항상 표시

### 2-3. 모드

| 모드 | 가능한 조작 |
|---|---|
| 기본 모드 | 터뜨리기(블록 위에서 긋기), 길게 눌러 세부 메모 열기, 스크롤(빈 곳에서 시작) |
| 블록 편집 모드 | 블록 추가·이동·삭제·색 변경, 트레이 표시. 터뜨리기는 불가 |
| 텍스트 편집 모드 | 요약 메모 작성·이동 |

- 블록 편집 모드와 텍스트 편집 모드는 따로 작동한다.
- **터뜨리기 끄기**: 플롯을 빠르게 훑어볼 때 사용. 켜 두면 블록 위에서 그어도 스크롤만 되고 터뜨리기가 발동하지 않는다.
- 기본 모드에서는 블록이 절대 움직이지 않는다.

## 3. 타임라인 시트

### 3-1. 구조
- 시트마다 화수 구간을 자유롭게 입력한다 (예: 시트 1 = 1~17화, 시트 2 = 18화).
- 무한 확장 가능하며, 시트를 추가·삭제할 수 있다.
- **시트 1장 = 3×5칸**
  - 모바일: 가로 5칸 × 세로 3칸
  - 데스크탑: 가로 3칸 × 세로 5칸 (진행 방향에 맞춰 회전) `[가정]`
  - 가운데 줄이 기본 배치 줄이고, 위아래 줄은 여유 공백이다. 여유 공백에도 블록을 놓을 수 있다.
- 시트 1장에 놓을 수 있는 블록 수는 제한하지 않는다 (빈칸이 있는 만큼, 최대 15개). Phase 2 테스트에서 4개 제한을 없앴다.
- 내부적으로 1칸 단위로 스냅하며, 블록끼리 겹치지 않는다.
- 블록을 들고 있는 동안에는 화면이 스크롤되지 않는다. 트레이에서 꺼낸 블록은 자동 스크롤도 하지 않고, 시트 블록을 옮길 때만 화면 끝에 0.4초 머물면 자동 스크롤한다. 아래 스크롤 구역은 트레이 위쪽부터 화면 맨 아래까지이며, 깊이 내릴수록 빨라진다.
- 삭제는 트레이 오른쪽의 삭제 칸에 놓을 때만 일어난다 (트레이의 색 슬롯 위는 스크롤 구역).
- 배경에는 격자 등 텍스트를 가리는 요소를 두지 않는다.
  - 칸 안내는 편집 모드에서 블록을 끌 때만 놓일 칸을 하이라이트하는 정도로 한다.

### 3-2. 시트 메모
- 시트의 화수 라벨을 탭하면 시트 메모 화면이 열린다.
- 같은 화면에서 화수 구간도 수정한다.

### 3-3. 화수 검색
- 화수를 입력하면 그 화수가 들어 있는 시트로 이동한다.
- 구간 중간의 화수를 검색하면 해당 시트의 시작점으로 이동한다 (예: 5화 검색 → 1~17화 시트).

## 4. 블록

### 4-1. 기본
- 정사각형이며, 모바일에서는 작은 크기를 상정한다.
- 데이터: 색 슬롯, 소속 시트, 칸 위치, 요약 메모, 세부 메모(제목·본문), 완성도
- 같은 시트에 같은 색 블록을 2개 이상 놓을 수 있다. `[가정]`
  - 이때 세부 메모의 순서는 칸 순서(위에서 아래, 왼쪽에서 오른쪽)를 따른다.

### 4-2. 색상 (4슬롯 방식)
- 색 슬롯은 4개이며, 처음에는 파스텔 프리셋 4색이 들어 있다.
- 슬롯 색 변경: 슬롯을 탭하고 팔레트에서 원하는 색을 고른다.
  - 그 슬롯을 쓰는 기존 블록의 색이 모두 자동으로 바뀐다.
- 프리셋으로 초기화할 수 있다 (슬롯별).
- 프리셋 4색(확정): 연핑크 `#F2CCC3`, 로즈브라운 `#C79C90`, 블루 `#C0D4EE`, 크림 `#F6DCAE`. 배경은 아이보리 `#F4F1EA`.
- 블록 외곽선: 설정에서 켜고 끌 수 있다 (옅은 1px 테두리).
- 디자인 세부 값은 `docs/design-tokens.md`를 따른다.
- 색 삭제 기능은 없다 (교체 방식만 제공).
- 블록 편집 모드에서 블록마다 다른 슬롯으로 색을 바꿀 수 있다: 트레이의 색을 다른 색 블록 위에 끌어다 놓는다.
- 슬롯 색 변경: 트레이의 + 버튼으로 색 슬롯 패널을 열고, 색을 눌러 고른다.
- 색 의미
  - 슬롯 1개에 의미 1개 (예: 노랑 = 복선)
  - 세부 메모 상단에 표시된다.
  - 세부 메모에서 수정하면 같은 색의 모든 메모에 반영된다.
  - 슬롯 색을 바꿔도 의미는 그대로 유지된다.

### 4-3. 요약 메모
- 간단한 제목 수준의 짧은 텍스트
- 글자 크기: 설정에서 작게(11px) 또는 크게(12px, 기본) 선택
- 블록 안이나 밖(빈칸)에 자유롭게 놓을 수 있다.
- 블록과 블록 사이에 끼워 놓을 수는 없다.
- 텍스트 편집 모드에서만 이동할 수 있다.

### 4-4. 완성도
- 설계, 검토, 완성의 3단계 (세부 메모에서 설정)
- 블록 겉모습에는 표시하지 않는다.
- 터뜨리기 연출에만 영향을 준다 (6-3 참고).

### 4-5. 삭제와 복구
- 삭제: 블록 편집 모드에서 블록을 트레이로 끌어다 놓는다 (이동 조작을 그대로 재사용).
- 복구: 되돌리기 버튼을 누르면 직전 동작부터 차례로 취소한다 (최대 20단계, 앱을 닫으면 기록이 초기화됨).

## 5. 세부 메모 화면

- 진입: 기본 모드에서 블록을 길게 누른다 (다른 조작보다 우선 실행).
- 길게 누르는 동안 블록이 눌려 들어가고, 블록 색보다 조금 진한 테두리(3px, 가장자리를 살짝 흐리게)가 전체적으로 천천히 드러난다. 가장 진할 때도 불투명도 50% (0.12초 뒤부터 표시). 0.5초가 되면 별도 연출 없이 바로 메모 화면이 아래에서 올라온다.
- 다른 화면으로 전환되는 방식이다.
- 구성
  - 상단: 색 의미 (수정 가능)
  - 같은 색 블록의 메모를 시트 순서대로 세로로 나열한다.
  - 누른 블록의 메모에 포커스가 가고, 위아래로 스크롤하면 이전·이후 화의 메모가 보인다.
- 메모 1개 구성: 화수 표시, 요약 메모(있으면), 제목, 본문(서식 없는 메모장), 완성도 선택
- 입력은 바로 자동 저장된다. 화면을 열 때 키보드는 자동으로 띄우지 않는다.
- 닫기: 왼쪽 위 '‹ 시트' 버튼
- 색 전체 복사: 그 색의 모든 메모를 한 번에 클립보드로 복사한다. 형식은 다음과 같다.
  ```
  [1~17화] 제목
  본문

  [18화] 제목
  본문
  ```
- 향후 확장: 앱 안에 내장된 캐릭터 아이콘 프리셋을 메모에 추가 (초기 범위에서는 제외)

## 6. 터뜨리기 (게임 요소)

### 6-1. 발동
- 기본 모드이고 터뜨리기 끄기가 꺼져 있을 때 동작한다.
- 블록 위에서 손가락을 대고 그으면 시작한다. 빈 곳에서 시작하면 스크롤이 된다.

### 6-2. 연결 규칙
- 최소 2개부터 터진다.
- 최대 5개까지 연결된다. 6개 이상이 닿으면 먼저 이어진 5개만 터진다.
- 경로는 빈칸(여유 공백 포함)과 같은 색 블록 위로만 지날 수 있다.
- 방향 제약이 없어서 대각선과 자유 곡선으로 그을 수 있고, 꺾는 횟수에도 제한이 없다.
- 시트 경계를 넘어 다른 시트로 이어 그을 수 있다.
- 다른 색 블록에 닿으면 저항 효과가 나고, 그 터뜨리기는 무효가 된다.

### 6-3. 연출 단계

| 조건 | 연출 |
|---|---|
| 공통 | 블록이 순서대로 블록 색 별 조각으로 흩어지고, 마지막 블록에서 금색 원과 금색 반짝이가 퍼짐. 연결 개수가 많을수록 커짐 |
| 완성 블록이 1개 이상 포함 (A) | 완성 블록마다 작은 금색 고리, 전체 중심에서 금색 원과 금색 반짝이 |
| 모든 블록이 완성 (B) | 금색·남색만 사용. 블록이 금색 별 조각과 남색 반짝이로 흩어지고, 터진 블록들을 순서대로 잇는 금색 별자리, 두 겹의 큰 금색 원, 금색·남색 반짝이, 화면 곳곳에서 반짝이는 별, 별똥별 3개 |

- 컨셉: 별과 밤하늘. 파스텔 화면에서 튀지 않도록 차분한 금색(`#E3C07E`)과 어두운 남색(`#3A4670`)을 낮은 불투명도로 사용한다.
- 글자 배너, 색종이, 화면 번쩍임, 안개는 쓰지 않는다 (Phase 3 테스트에서 제외).
- 터진 뒤에는 블록이 원래 위치로 돌아온다 (연출 전용, 데이터 변화 없음).

### 6-4. 콤보
- 터뜨린 뒤 1초 안에 다음 긋기를 시작해서 **다른 색**을 터뜨리면 콤보가 1씩 쌓인다 (처음 터뜨리기는 0, 다음 다른 색부터 1콤보).
- 같은 색을 터뜨리거나, 1초 이상 긋지 않으면 콤보가 끊긴다. 터뜨리지 못하고 끝난 긋기는 그때부터 다시 1초를 센다.
- 1콤보부터 화면 가운데에 금색 `숫자 + COMBO`가 나타난다. 숫자가 오를 때 이전 숫자는 위로 날아가고 새 숫자가 크게 떨어지듯 들어와 출렁이며, 금색 원과 반짝이가 함께 나온다. 콤보가 높을수록 글자가 조금씩 커진다 (10콤보까지).
- 끊기면 위로 떠오르며 사라진다.
- 터지는 연출이 진행되는 동안에도 다른 블록은 바로 그어서 터뜨릴 수 있다 (터지는 중인 블록만 제외).

### 6-5. 진동 → 시각 피드백으로 대체 (Phase 0 검증 완료)
- 실기기 결과: 표준 진동 API 미지원, 스위치 우회 방식 A·B 모두 실패. iOS 기본 스위치를 직접 누를 때만 진동이 났다.
- 결론: 웹앱에서 iPhone 진동을 낼 수 없다고 보고, 진동 기능과 진동 끄기 설정을 범위에서 제외한다.
- 손맛은 시각 피드백으로 구현한다.
  - 집을 때: 확대와 그림자
  - 놓을 때: 탄성 착지, 착지 순간 시트가 살짝 흔들림
  - 겹칠 때: 튕겨 돌아옴과 좌우 흔들림
  - 칸을 지날 때: 놓일 칸 하이라이트가 톡 튀는 효과
  - 터뜨리기: 화면 흔들림, 연결된 블록이 순서대로 살짝 눌렸다 튀어 오름

## 7. 데이터 보호

| 기능 | 내용 |
|---|---|
| 저장 | 기기 브라우저 내부 저장소(IndexedDB). 서버에 데이터를 보내지 않음. 변경 0.3초 뒤 자동 저장, 앱을 내릴 때 즉시 저장. 읽기에 실패하면 기존 데이터를 덮어쓰지 않도록 저장을 멈춤 |
| 백업 | 백업 파일(JSON) 내려받기와 불러오기(복구) |
| 백업 알림 | 마지막 백업 후 일정 기간이 지나면 앱 안에 알림 표시 `[가정]` |
| 저장소 보호 | 홈 화면에 설치해서 사용하고, 브라우저에 영구 저장소를 요청 |

## 8. 실행·배포 방식

**결론: 무료 정적 호스팅에 앱을 올리고, 폰에서 PWA(홈 화면 설치)로 쓴다.**

| 항목 | 내용 |
|---|---|
| 호스팅 | GitHub Pages (권장, 절차가 가장 간단함) 또는 Cloudflare Pages (코드도 비공개로 두고 싶을 때) |
| 올라가는 것 | 앱 코드만. 작성한 플롯 데이터는 폰 안에만 있음 |
| iPhone 설치 | Safari로 주소 접속 → 공유 버튼 → "홈 화면에 추가" |
| 오프라인 | 첫 접속 이후에는 인터넷 없이 실행 |
| 비용 | 0원 |

- iOS Safari는 오래 쓰지 않은 사이트의 저장 데이터를 지울 수 있다.
- 홈 화면에 설치한 웹앱은 이 정책의 예외로 알려져 있지만, 정기 백업을 반드시 병행한다.

## 9. 기술 스택

| 항목 | 선택 |
|---|---|
| 언어 | HTML, CSS, 순수 JavaScript (빌드 과정 없음) |
| 조작 | Pointer Events와 CSS transform |
| 연출 | Canvas 파티클과 CSS 애니메이션 |
| 저장 | IndexedDB |
| 오프라인 | PWA (manifest와 서비스워커) |

## 10. 남은 확인 사항 (테스트에서 검증)
1. 같은 시트에 같은 색 블록을 여러 개 놓아도 되는지 (Q10, 답변 없음. 현재 가능한 것으로 가정)
2. 데스크탑에서 시트를 3×5로 회전 배치하는 것이 맞는지
3. 백업 알림 기능이 필요한지

## 11. Phase 0 검증 결과 (iPhone, 홈 화면 앱)

| 항목 | 결과 |
|---|---|
| 홈 화면 설치, 오프라인 실행 | 정상 |
| 앱 재실행 후 데이터 유지 | 정상 |
| 영구 저장소 요청 | Safari가 거부함 → 백업 기능으로 보완 |
| 끌기 프레임 | 평균 58fps, 최장 끊김 29ms (양호) |
| 끌기·스냅, 길게 누르기, 긋기/스크롤 구분 | 정상 |
| 진동 | 불가 → 시각 피드백으로 대체 |
