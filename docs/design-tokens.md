# 디자인 토큰 v1.0 (Phase 1 확정)

## 색상

| 용도 | 값 |
|---|---|
| 배경 | `#F4F1EA` 아이보리 |
| 블록 슬롯 1 (프리셋) | `#F2CCC3` 연핑크 |
| 블록 슬롯 2 (프리셋) | `#C79C90` 로즈브라운 |
| 블록 슬롯 3 (프리셋) | `#C0D4EE` 블루 |
| 블록 슬롯 4 (프리셋) | `#F6DCAE` 크림 |
| 글자 | `#3B3833` |
| 보조 글자 (화수 라벨 등) | `#8A847A` |
| 블록 안 글자 | `rgba(40, 36, 30, 0.85)` |
| 시트 구분선 | `#E3DDD1` |

## 블록

| 항목 | 값 |
|---|---|
| 크기 | 54px (모바일 기준. 화면이 좁으면 폭에 맞춰 축소) |
| 칸 간격 | 6px |
| 모서리 | 9px |
| 하단 음영 | `inset 0 -3px 0 rgba(0, 0, 0, 0.08)` |
| 외곽선 (설정, 기본 끔) | `inset 0 0 0 1px rgba(60, 45, 30, 0.14)` |
| 블록 안 글자 | 11px, 굵기 600 |

## 글자

| 항목 | 값 |
|---|---|
| 글꼴 | `-apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif` |
| 바깥 메모 (요약 메모) | 기본 12px. 설정에서 작게 11px / 크게 12px 선택 |
| 화수 라벨 | 12px, 굵기 700, 보조 글자색 |
| 입력창 | 16px 이상 (16px 미만이면 iOS가 화면을 확대함) |

## 시트

| 항목 | 값 |
|---|---|
| 칸 배열 | 모바일 가로 5 × 세로 3, 데스크탑 가로 3 × 세로 5 |
| 시트 구분 | 구분선 1px, 시트 위아래 여백 12px (데스크탑은 세로 구분선) |
| 화수 라벨 | 시트 위 왼쪽 글자 |
| 배경 격자 | 없음 |

## 트레이

| 항목 | 값 |
|---|---|
| 형태 | 떠 있는 형 (화면 하단 가운데) |
| 위치 | 하단 안전 영역 + 14px |
| 모서리 | 22px |
| 배경 | `rgba(255, 253, 248, 0.97)` |
| 그림자 | `0 8px 24px rgba(60, 50, 30, 0.16)` |
| 슬롯 블록 | 블록 크기의 80% (약 43px) |
| 구성 | 색 슬롯 4개, 색 변경(+), 삭제 영역 |
| 표시 | 모바일은 편집 모드일 때만, 데스크탑은 항상 |
